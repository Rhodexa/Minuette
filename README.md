## ¿Ayuda?

### Entrar a modo configuración
1. Presioná el botón Configurar — Minuette va a crear su propio Wi-Fi!
2. Buscá Minuette entre tus redes Wi-Fi disponibles en tu celular
3. Conectate a Minuette — Clave: minuta12345
4. Tu celular va a abrir la página de configuración automaticamente

### ¿No se abre la página?
- No importa! podés abrirla manualmente.
- Si tu celu está conectado a Minuette
- Podés abrir un navegador, y poner este link: \
http://192.168.4.1

### ¿No podés abrir http://192.168.4.1?
Chequeá estos detalles:
1. Asegurate de que está conectado a Minuette
2. Apagá tus datos móviles
3. Algunos celulares detectan redes sin internet (Como Minuette) y preguntan si querés mantener la conexión — Seleccioná Si / Solo esta vez. Este es un problema conocido en Samsung
4. Probá otro buscador
5. Probá desde una computadora que también esté conectada a Minuette
